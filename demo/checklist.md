# ProofGrid — final demo checklist

## Before recording
- [ ] Use a 16:9 capture at 1280×720 or 1920×1080.
- [ ] Browser zoom at 100%.
- [ ] Close unrelated tabs, extensions, notifications and bookmarks bar.
- [ ] Start ProofGrid from a clean localStorage state.
- [ ] Open `/?record=1` for the automatic demo director.
- [ ] Do one rehearsal with no voice-over.

## During recording
- [ ] Do not move the mouse unless the automatic run fails.
- [ ] Keep the Proof Grid visible long enough to read the status counts.
- [ ] Make sure the verified and concern state changes are captured.
- [ ] Make sure the seller questions panel is visible.
- [ ] Do not demonstrate anything outside the verified POC.

## Voice-over
- [ ] Read `voiceover.txt` naturally, not like an advertisement.
- [ ] Keep “A claim is not proof” as the memorable hook.
- [ ] Do not call Evidence Coverage a trust score.
- [ ] Do not imply that ProofGrid verifies a car automatically.

## Final edit
- [ ] 60–90 seconds total.
- [ ] No dead time over 1.5–2 seconds.
- [ ] Voice level consistent.
- [ ] Captions/subtitles legible on mobile.
- [ ] Export H.264 MP4, 1080p if possible.
- [ ] Watch once with sound OFF: the story should still make sense.
- [ ] Watch once on a phone-sized player.
