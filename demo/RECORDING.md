# ProofGrid demo recording

## Automatic recording mode

Run the app:

```bash
node server.mjs
```

Open:

`http://127.0.0.1:4173/?record=1`

The page automatically performs the demo and displays synchronized on-screen captions. Normal ProofGrid behavior is unchanged without `?record=1`.

## Recommended capture

- Resolution: 1280×720 or 1920×1080
- Browser zoom: 100%
- Hide bookmarks/extensions if recording manually
- Do not move the mouse during the automatic sequence
- Add the final voice-over from `voiceover.txt`

## Final submission

Use the automatic recording as the visual base, then add a clean voice-over. Keep the final export below the competition's maximum demo duration.
