# ProofGrid — demo timeline

| Time | Screen action | Spoken idea |
|---|---|---|
| 0–5s | Home/hero | A claim is not proof. |
| 5–10s | Demo listing loaded | ProofGrid separates claims from verifiable evidence. |
| 10–16s | Analyze → Proof Grid | Evidence-bearing claims are extracted without a trust score. |
| 16–21s | Focus service-history card | Each claim maps to specific supporting evidence. |
| 21–25s | Mark service as verified | Real documentation changes that claim to verified. |
| 25–30s | Mark timing belt + brakes verified | The grid updates claim by claim. |
| 30–35s | Mark accident-free as concern | Concerns remain explicit instead of disappearing into a score. |
| 35–40s | Next best action | Remaining gaps become concrete actions. |
| 40–45s | Seller questions | ProofGrid generates specific questions to send. |
| 45–50s | Verification-aid note | It is not a purchase recommendation or vehicle-quality score. |
| 50–58s | Final Proof Grid | Claimed, proven, and what to ask next. |
